يُعد alles بديلاً خاصاً لمنظومة Google. بريدك وتقويمك ومستنداتك وملفاتك وصورك وجهات اتصالك ومهامك وأموالك وكلمات مرورك كلها في تطبيق واحد على جهاز تتحكم فيه، بدلاً من خوادم شخص آخر.

صُمم alles لشخص واحد. تبقى بياناتك الأساسية في مجلد تتحكم فيه، وأنت من يقرر الخدمات الخارجية التي تتصل بها. وهناك أيضاً aide، وهو مساعد ذكاء اصطناعي يمكنه العمل مع التطبيقات عندما توافق على إجراءاته. استخدمه إن كان مفيداً لك؛ فالأدوات المحلية تعمل من دون نموذج ذكاء اصطناعي.

## البدء

على macOS أو Linux، شغّل:

</div>

```bash
curl -fsSL https://raw.githubusercontent.com/jxherc/alles/main/install.sh | sh
```

<div dir="rtl">

يُنزّل التطبيق وحده، ويضبطه كخدمة تعمل في الخلفية، ويعرض كل خطوة أثناء التثبيت. يبقى alles قيد التشغيل بعد إغلاق الطرفية، ويعمل من جديد بعد إعادة تشغيل الجهاز. يحتاج إلى Python 3.11 أو إصدار أحدث؛ وعلى Debian أو Ubuntu يعرض المثبّت إضافة وحدة venv الخاصة بـ Python إذا كانت مفقودة.

بعد ذلك افتح [http://localhost:6769](http://localhost:6769) واتبع خطوات الإعداد. لا تحتاج إلى مفتاح API للبدء. ومن ثمّ يتولى الأمر `alles` الباقي: وحده يعرض ما إذا كان alles يعمل وكيف تفتحه، و`alles doctor` يفحص التثبيت، و`alles config` يفتح ملف الإعدادات.

افتراضياً، لا يمكن الوصول إلى alles إلا من هذا الجهاز، ويبدأ من دون كلمة مرور. **قبل وضعه على شبكتك**، اضبط له كلمة مرور واختر من يمكنه فتحه: الأمر `alles access lan` يفعل الأمرين. للوصول عبر الشبكة المحلية والوصول العام متطلبات مختلفة؛ اقرأ أولاً قسم [الأمان](../../specifications.md#security--read-before-exposing-it). بعد التثبيت مباشرة يسألك إن كنت تريد كلمة مرور (8 أحرف أو أكثر؛ يضبطها `alles password` أو يغيّرها لاحقًا) وإن كانت أجهزتك الأخرى ستفتحه.

### تثبيته على قرص آخر

شغّل التثبيت من مجلد على القرص فيُثبَّت alles في مجلد `Alles` هناك:

```bash
cd /Volumes/External
curl -fsSL https://raw.githubusercontent.com/jxherc/alles/main/install.sh | sh
```

أو حدّد المجلد بنفسك من أي مكان:

```bash
curl -fsSL https://raw.githubusercontent.com/jxherc/alles/main/install.sh | ALLES_HOME=/Volumes/External/Alles sh
```

عندها يحفظ alles كل شيء في ذلك المجلد: مستنداتك وملفاتك ظاهرة، وقاعدة البيانات والتطبيق والنسخ الاحتياطية والإعدادات في مجلد مخفي `.alles` داخله. لا يبقى على هذا الحاسوب إلا الأمر `alles` والملف الصغير الذي يشغّل الخدمة، وكل أمر لاحق (ومنه `alles update`) يجد المجلد وحده. إذا لم يكن القرص موصولاً، يتوقف التثبيت قبل أن ينشئ أي شيء، ويقول `alles` إن القرص غير موجود، وتنتظر الخدمة القرص بدلاً من أن تبدأ فارغة. ويختار `ALLES_PORT=8000` منفذاً آخر بالطريقة نفسها.

على جهاز mac، يسأل أول تشغيل هل يُسمح لـ `alles-server` بالوصول إلى ملفات على وحدة تخزين قابلة للإزالة. اضغط سماح، وإلا فلن تستطيع الخدمة فتح أي شيء على القرص. يحتاج ذلك أدوات سطر الأوامر من apple (`xcode-select --install`)؛ وإذا ثبّتها لاحقًا، شغّل `alles restart`.

### استخدامه من جهاز آخر

</div>

```bash
alles access lan
```

<div dir="rtl">

يطلب كلمة مرور للمالك، ثم يعيد تشغيل alles حتى يتمكن هاتفك وحواسيبك الأخرى من فتحه، ويعرض العناوين التي تستخدمها، مثل `http://100.101.102.103:6769`. والأمر `alles access device` يجعله خاصاً بهذا الحاسوب من جديد.

### فتحه على نطاقك الخاص

```bash
alles access domain alles.example.com
```

يصبح كل تطبيق بعد شرطة مائلة: `alles.example.com/docs` و`alles.example.com/plan`. أضف `subdomain` (`alles access domain alles.example.com subdomain`) ليحصل كل تطبيق على عنوانه الخاص مثل `docs.alles.example.com`، ويحتاج ذلك إلى سجل DNS وشهادة بحرف بدل. لا يصنع alles الشهادة بنفسه: وجّه النطاق إلى هذا الحاسوب واجعل وكيل https (caddy أو nginx أو نفق cloudflare) يرسله إلى `http://127.0.0.1:6769`. والأمر `alles access domain off` يلغي ربطه.

### اجعل andromeda بحث متصفحك

من الإعدادات › andromeda › البحث الافتراضي تنزّل إضافة صغيرة لـ chrome وbrave وedge وhelium: فك ضغطها، وافتح `chrome://extensions`، وشغّل وضع المطوّر، ثم حمّل المجلد، فيصبح andromeda البحث الافتراضي. وأي متصفح آخر يمكنه استخدام عنوان البحث الظاهر هناك كمحرك بحث مخصص.

أما safari على iphone أو ipad فيعرض قائمة apple فقط، لذلك يحتوي `safari/` على تطبيق صغير فيه إضافة safari: أبقِ google محرك بحث safari، وسترسل الإضافة كل بحث على google أو bing أو duckduckgo أو yahoo أو ecosia أو baidu إلى andromeda. ابنِه في xcode بفريق مطوّري apple الخاص بك، وشغّله من الإعدادات › التطبيقات › safari › الامتدادات، واسمح له على كل المواقع، ثم أدخل عنوان alles في نافذته.

### تشغيله من الشفرة المصدرية

للتطوير، أو لتشغيله من دون الخدمة. على Debian أو Ubuntu، شغّل أولاً `sudo apt install git python3-venv`.

</div>

```bash
git clone https://github.com/jxherc/alles.git
cd alles
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
python app.py
```

<div dir="rtl">

يمكنك هنا أيضاً إعداد الوصول من الأجهزة الأخرى بالأمر `python cli.py access lan`؛ ثم شغّل `python app.py` من جديد.

إذا كنت تفضّل Docker:

</div>

```bash
docker build -t alles .
docker run -p 127.0.0.1:6769:6769 -v alles-data:/app/data alles
```

<div dir="rtl">

بهذا يبقى الوصول مقتصراً على جهازك، وتُحفظ بياناتك في وحدة التخزين `alles-data`. احتفظ بوحدة التخزين هذه عند استبدال الحاوية.

## ما الذي يمكنك فعله

| التطبيق | استخدمه من أجل |
| --- | --- |
| home | رؤية يومك وفتح تطبيقاتك وتدوين مهمة بسرعة |
| aide | الدردشة مع نموذج مُعدّ والموافقة على الإجراءات في مساحة عملك |
| andromeda | البحث في الويب والحصول اختيارياً على نظرة عامة مع المصادر، ويمكن جعله محرك البحث في المتصفح |
| plan | إدارة تقويم ومهام وتذكيرات وعدّادات تنازلية |
| inbox | قراءة البريد وإدارة جهات الاتصال بعد ربط حسابك |
| docs | كتابة ملاحظات Markdown ويوميات |
| files | تصفّح التخزين المحلي أو المتصل والنسخ المتاحة دون اتصال والصور |
| library | حفظ المقالات وقوائم القراءة |
| health | تتبّع العادات والسجلات الصحية |
| finance | تتبّع الحسابات والمعاملات والميزانيات والاشتراكات |
| vault | تخزين الأسرار وكلمات المرور ومفاتيح المرور مشفّرةً، وتعبئة بيانات الدخول والبطاقات والعناوين في chrome بإضافة alles |
| server | التحقق من الحالة وإعدادات الوصول والنسخ الاحتياطية والتحديثات |

المعاملات اليدوية الجديدة المحفوظة في دفتر الحسابات المالي المحلي يمكن التراجع عنها. يحذف التراجع تلك المعاملة بعينها فقط، وما دامت تفاصيلها المحفوظة لم تتغير؛ وإذا انقطع الرد، تبقى إعادة المحاولة متاحة للمعاملة نفسها. أما معاملات Actual وعمليات الاستيراد والتحويلات فتمر بمسارات المراجعة والحذف المعتادة لها.

بعض الميزات تحتاج إلى اتصال قبل أن تعمل. أضف حساب IMAP/SMTP للبريد، واربط خدمة للتخزين عبر الإنترنت أو للخدمات المصرفية، وأضف نموذجاً من **settings → models** إذا أردت استخدام aide. تعمل النماذج المحلية عبر Ollama أيضاً.

في البريد اختر gmail أو outlook أو icloud أو yahoo أو fastmail فيمتلئ النموذج وحده؛ ويسجّل gmail الدخول عبر google بعد إعداد لمرة واحدة في google cloud يرشدك إليه alles خطوة بخطوة (نزّل ملف json للعميل وأفلته). مزامنة البنوك موجودة في **المالية ← اتصالات البنوك** (plaid لمعظم بنوك كندا والولايات المتحدة، أو simplefin). لمراسلة aide من هاتفك، فعّل telegram أو imessage أو discord في **الإعدادات ← الاتصالات**؛ و**الإعدادات ← هذا الجهاز** يثبّت node وpi ومتصفح aide بنقرة واحدة.

الواجهة متاحة بـ english, français, español, 简体中文, 繁體中文, 日本語, 한국어 والعربية. اختر لغتك من **الإعدادات ← اللغة والمنطقة**.

يشرح [specifications.md](../../specifications.md) بالتفصيل سلوك التطبيقات والبنية وواجهة API والإعدادات.

## بياناتك والنسخ الاحتياطية

عند تثبيت alles، تُحفظ قاعدة بياناتك والملفات التي يديرها في `~/.local/share/alles/data` على Linux أو في `~/Library/Application Support/Alles/data` على macOS؛ ويعرض `alles status` مكانها. أما عند التشغيل من الشفرة المصدرية فيستخدم `data/`، أو `ALLES_DATA` إذا ضبطته. أبقِ هذا المجلد خاصاً واحتفظ بنسخة احتياطية منه. يتلقى المزودون الخارجيون الطلبات التي ترسلها إليهم عبر اتصالاتهم.

مستنداتك وملفاتك في مجلد واحد تراه، `~/Alles`، والمستندات في `~/Alles/Docs`، فيعرض تطبيق الملفات كل ما كتبته. النسخ الاحتياطية اليومية تُحفظ بجانب مجلد البيانات بعيدًا عن النظر. التثبيت الأقدم من نوفمبر ينتقل إلى هذا الترتيب عند تشغيل `alles update accept` (أو `alles folders move`)؛ المجلدات التي اخترتها بنفسك أو الموجودة على قرص آخر تبقى في مكانها، ويوضح `alles doctor` السبب.

افتح **settings → backup** لتنزيل نسخة احتياطية مشفّرة. يمكنك أيضاً إرسال نسخة يدوياً إلى مجلد WebDAV موجود عبر HTTPS أو إلى حاوية تخزين متوافقة مع S3، أو ضبط نسخ احتياطية محلية يومية أثناء الإعداد الأولي. احتفظ بمفتاح الاسترداد في مكان خارج alles حتى تتمكن من الوصول إليه إذا توقف التطبيق عن العمل.

يتحقق alles من النسخة الاحتياطية ويجهّز الاستعادة قبل تطبيقها. أوقف التطبيق، ثم اتبع الأمر الذي يعرضه عليك. اقرأ [تفاصيل النسخ الاحتياطي والاستعادة](../../specifications.md#your-data-where-everything-lives) قبل نقل تثبيت موجود.

## التحديث والإزالة

يجلب `alles update` أحدث إصدار ويحتفظ بالإصدار السابق، لذا يستطيع `alles update rollback` العودة إليه مع بياناتك. ويزيل `alles uninstall` برنامج alles ويحتفظ ببياناتك الشخصية. ويعرض `alles help` جميع الأوامر. يسمّي `alles status` الإصدار باختصار الـ commit الخاص به ويخبرك عند صدور إصدار أحدث. ويعرض `alles tools` ما يستطيع aide استخدامه (node وpi ومتصفحه)، ويثبّتها `alles tools install`. يتيح لك `alles ask` و`alles chat` التحدث مع aide من الطرفية مباشرة، ويختصر `alles logs --level warn --since 1h` السجل إلى ما يهم، وينشئ `alles backup` نسخة احتياطية مشفّرة، ويطبع `alles dump` ملخصًا بلا أسرار للإبلاغ عن خطأ.

بُني alles باستخدام FastAPI وSQLite وJavaScript الخالصة وCSS، ولا توجد خطوة بناء للواجهة الأمامية. التفاصيل التقنية موجودة في [specifications.md](../../specifications.md).
