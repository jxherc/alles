# September 21 cleanup evidence

This follows the [repair pass](repair-2026-09-21.md). It removes proven unused implementations,
repairs current Files behavior, and keeps active apps, compatibility APIs, and owner data intact.
It is not a claim that every old line in Alles is obsolete or that every external integration works.

## removal audit

Deletion candidates were traced from the app bootstrap, checked for repository consumers, and compared
with the currently rendered interface. The conservative module graph now reaches all 86 shipped
frontend modules; a regression test fails if a shipped module becomes disconnected or a dependency
is missing.

| Item | Location | Notes |
|---|---|---|
| Retired Files browser | `static/js/files.js` | No runtime importer. `filesphase7.js` owns the shipped Files workbench. Current sorting and icon contracts now test that implementation. |
| Retired research cards and document-question composer | `static/js/research.js`, `static/js/ragquery.js` | Neither module is loaded. Current Andromeda research, document context, and server APIs remain. |
| Disconnected behavior selector | `static/js/aidebehavior.js`, session/settings callbacks | The old composer select is absent. Current Settings behavior selection and session behavior remain. |
| Unused shared helpers | date picker, Docs, KOKUEN, modes, sessions, setup wizard, System, voice | No remaining callers after retired modules were removed. Active menu/focus controllers, recording, session creation and graph rendering remain. |
| Seven private Python helpers | chat/files routes; file operations, Discord and secret store services | No repository consumers. Current endpoint routing, metadata migration, verified file operations, delivery-result handling and keyring logic remain. |
| Obsolete interface styles | `static/style.css`, `static/kokuen.css` | Removed research cards and selectors belonging only to the old Files browser. Shared selectors used by other live screens remain. |
| Nonfunctional live-voice action | `static/index.html`, `static/js/app.js`, `static/js/voice.js` | It displayed a success toast without opening a voice connection. Removed the misleading button; ordinary microphone input and public realtime discovery/session APIs remain. |
| Retired UI test scripts | old Aide behavior/research source tests and five old Files/Aide browser scripts | Their target controls no longer exist. Current Files/voice contracts, dependency inventory and real-browser regressions cover retained behavior. |
| Old offline cache generation | `static/sw.js` | Version v259 refreshes the shell without removed modules. It does not delete owner files or IndexedDB data. |

Duplicate implementations were removed only where a current owner exists. Similar-looking live
controls, endpoint adapters, limits, timeouts, migration paths, backup/recovery logic, and historical
reference documents were retained. No framework, dependency, schema, or public API migration is included.

## confirmed repairs

- Saved Files links with `sort` and `order` now reach the current listing API. Valid values survive
  folder navigation; invalid values fall back to the normal name ordering.
- WebDAV and S3 location icons now exist in the shared icon catalog instead of rendering a fallback box.
- Mobile folder breadcrumbs inherited wrapping from the old interface, spilling above and below the
  fixed header. The current breadcrumb stays on one horizontally scrollable row with keyboard access.
- The mobile transfer panel now respects the shell rail under reduced motion. Without the animated
  containing block, its viewport-sized width extended underneath the rail and clipped its labels.
- Control inventory tests now measure the proportion of resolved templates, rather than requiring a
  minimum number of old controls to remain. Generated inventories exclude retired source files.
- The offline browser gate checks the new cache and verifies that retired modules are absent.

## verification

All mutable checks use owned temporary data and separate loopback ports. Disabled fake remote
locations verify icon rendering without contacting storage providers. Browser checks exercise actual
application code and local APIs; they do not prove a live external provider integration.

- Full Python repository suite: 5,574 passing with 6 environment-dependent skips.
- JavaScript suite: 578 passing; Ruff lint and format checks pass.
- Current Files gate: deep-link sorting, invalid fallback, keyboard folder navigation, breadcrumb
  containment, both remote icons, and retained microphone UI at 1440px and 390px.
- Phase 7 Files gate: populated local file operations and recovery, desktop/mobile and keyboard paths.
- Finished-surface gate: primary/specialist navigation, current controls, light/dark, mobile,
  reduced motion and 200% zoom.
- Contrast passes across 184 surfaces / 2,755 text observations. Resting-control checks pass across
  92 surfaces / 1,518 visible controls, with console checks.
- PWA gate: cached shell, removed-module exclusion, offline navigation and reconnect.
- Canonical design audit: 0 errors, 192 explained warnings (three obsolete small-type warnings removed),
  no newly introduced warning. Existing 72 nested-boundary and 120 small-type findings remain documented.

The final design review checks existing tokens and component geometry, clear labels, preserved tasks
and recovery, visible keyboard focus, custom controls, no new assets or animation, both themes, 200%
zoom, mobile containment, and reduced motion. No new visual direction or system-wide component
pattern is introduced. Existing design warnings remain explicit rather than being claimed resolved.

Full-suite and publication results are recorded in `.agent/TASK.md` at the publication checkpoint.
