## release boundaries

- **fonts:** No font files are bundled. Core UI uses the host system font stack and has no runtime font request.
- **models:** No model weights are bundled. The local JSON file contains only reviewed hardware-fit metadata.
- **skills:** No third-party skill package is bundled. Owner-installed skills remain owner data and are outside release artifacts.
- **adapted code:** Inspiration entries record product and interaction references only. They do not claim copied code or shipped companion software.
- **runtime ui:** Core UI makes no Google Fonts, Mermaid CDN, KaTeX CDN, unpkg, or cdnjs request.
