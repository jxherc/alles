# local inter

The owner requires Inter throughout the minimalist interface. The shared KOKUEN font token now follows the appearance font token instead of replacing it with a system font. Inter 4.1 normal and italic variable fonts are bundled locally under SIL OFL 1.1; no third-party font request is required.

Code and terminal surfaces retain the local monospace stack. Explicit serif or monospace appearance choices remain available. Verify actual loaded font faces and computed fonts, plus desktop, tablet, phone, native 200% zoom and forced-color layouts.
