# 0002: one primary action

Status: accepted for KOKUEN design work

## decision

Each screen exposes one visually primary action. Secondary actions use quieter text or icon treatment, and low-priority actions move into a custom overflow menu when space is limited.

## reason

Many equal buttons make dense specialist screens harder to scan. A stable action hierarchy reduces noise without hiding necessary behavior.

## consequence

The primary action may change with the user's current state, but two actions do not receive equal filled emphasis. Destructive actions remain explicit and never become primary only because they are colored.
