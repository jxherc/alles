# Settings context and Server feedback

Settings keeps its existing destinations and navigation order. Its compact header
shows the selected section name even when keyboard traversal moves the selected
tab out of the horizontal strip. An underline distinguishes selection from hover.
Changing context does not move keyboard focus or pull the strip away from the
control being traversed. The section name wraps and Close retains its full target.

Server status belongs beside the action or data it describes. Failed monitoring
marks the previous metrics unavailable; reentry does not leave a permanent loading
message. A saved policy refreshes its effective permissions and clears obsolete
error styling. Conditional host-permission fields obey their hidden state.

Service and backup refreshes update an attached content region. A late action
cannot replace a newer selected section. Keyboard focus returns to the matching
action after its redraw only when the previous action still owned focus. Log
entries display the runtime logger's saved timestamp.

Maintained browser checks separate real owned policy/authentication/log/export
and process restart from simulated service and remote-provider actions. Native
Safari/iPhone and live service/provider acceptance require separate evidence.
